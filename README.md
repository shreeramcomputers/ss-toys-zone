# SS Toys Zone — Website Demo

Static responsive business website for SS Toys Zone in Ganj Mandi, Sardhana, Meerut.

## Preview
Once GitHub Pages deployment is enabled and successful: https://shreeramcomputers.github.io/ss-toys-zone/

## Before using for the real business
- Verify the phone number and exact address with the owner.
- Replace the sample remote photos with approved business/product photos.
- Confirm categories, business hours and all public claims.
- This is an informational demo, not an online store; it does not accept orders or payments.
- Product categories are illustrative; check stock and prices with the shop.
